The repository was detached from the GitHub fork network and its history was rewritten into
a small, independent history without changing the tracked baseline file tree. There is
intentionally no local `upstream` remote or baseline tag. This file, the retained license, and
[`docs/CONTRIBUTION_MAP.md`](docs/CONTRIBUTION_MAP.md) preserve provenance and ownership boundaries.

Upstream changes are not merged automatically. Any future synchronization must be evaluated as
an isolated change and must not blur the distinction between upstream functionality and
TicketPilot-specific work.
